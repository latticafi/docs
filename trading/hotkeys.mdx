---
title: "Hotkeys"
---

Hotkeys are keyboard shortcuts that let you navigate Lattica more efficiently. The full list of hotkeys is as follows:

| Category   | Action                               | Shortcut |
| ---------- | ------------------------------------ | -------- |
| Every page | Search markets                       | <kbd>⌘K</kbd> |
|            | Keyboard shortcuts                   | <kbd>?</kbd> |
|            | Portfolio, and back                  | <kbd>⇧P</kbd> |
|            | Markets page, and back               | <kbd>⇧&#123;</kbd> |
|            | Cancel a chord, leave a field or row | <kbd>Esc</kbd> |

| Category | Action               | Shortcut |
| -------- | -------------------- | -------- |
| Terminal | Jump to the ticket   | <kbd>⌘→</kbd> |
|          | Search outcomes      | <kbd>/</kbd> |
|          | Bookmark this market | <kbd>⇧Space</kbd> |

| Category | Action        | Shortcut |
| -------- | ------------- | -------- |
| Go to    | Markets page  | <kbd>G E</kbd> |
|          | Positions     | <kbd>G P</kbd> |
|          | Open orders   | <kbd>G O</kbd> |
|          | Trade history | <kbd>G H</kbd> |
|          | Closed trades | <kbd>G C</kbd> |
|          | Outcomes      | <kbd>G M</kbd> |
|          | Top holders   | <kbd>G W</kbd> |
|          | Trades        | <kbd>G T</kbd> |
|          | Order book    | <kbd>G B</kbd> |
|          | Market rules  | <kbd>G R</kbd> |
|          | Deposit       | <kbd>G D</kbd> |

| Category | Action              | Shortcut |
| -------- | ------------------- | -------- |

|          | Price trigger       | <kbd>D L</kbd> |
|          | Trigger price       | <kbd>D P</kbd> |

| Category | Action                 | Shortcut |
| -------- | ---------------------- | -------- |
| Markets  | Previous / next market | <kbd>↑↓</kbd> |
|          | Switch side or team    | <kbd>←→</kbd> |

| Category   | Action                        | Shortcut |
| ---------- | ----------------------------- | -------- |
| Table rows | Move                          | <kbd>↑↓</kbd> |
|            | First / last row              | <kbd>⌘↑↓</kbd> |
|            | Open the row's market         | <kbd>↵</kbd> |
|            | Cancel order / close position | <kbd>Del⌫</kbd> |
